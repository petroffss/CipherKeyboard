# Контакты — ключи собеседников

## Суть
В приложении — список собеседников: добавить по открытому ключу (вставить текст или отсканировать QR), дать имя, сверить отпечаток, переименовать, удалить. Клавиатура берёт отсюда получателей и имена отправителей.

## Пользовательские истории
- Как пользователь, я хочу добавить ключ собеседника, отсканировав его QR при встрече или вставив присланный текст.
- Как пользователь, я хочу сверить отпечаток с собеседником, чтобы быть уверенным, что ключ его, а не подменённый.
- Как пользователь, я хочу удалить контакт, которому больше не пишу.

## Критерии приёмки
- AC1: Пустой список: текст «Пока нет контактов» и кнопка «Добавить контакт».
- AC2: Добавление: вставить строку `ckpub1:…` или отсканировать QR → показ отпечатка → поле «Имя» (1–40 символов после обрезки пробелов) → «Сохранить». Контакт появляется в списке с именем и первыми двумя группами отпечатка.
- AC3: Строка, которая не является ключом, → «Это не ключ CipherKeyboard»; «Сохранить» недоступна.
- AC4: Собственный ключ → «Это ваш собственный ключ»; не добавляется.
- AC5: Ключ, который уже есть, → «Этот ключ уже сохранён как «<имя>»»; дубль не создаётся. Имя, которое уже есть (без учёта регистра), → «Контакт с таким именем уже есть».
- AC6: Карточка контакта: имя, полный отпечаток, подсказка «Сверьте отпечаток с собеседником при встрече или по телефону», «Переименовать», «Удалить». Удаление — после подтверждения «Удалить контакт «<имя>»? Вы не сможете отправлять ему сообщения».
- AC7: Ключ контакта нельзя изменить на месте: другой ключ = удалить контакт и добавить заново (подмена ключа под тем же именем не проходит незаметно).
- AC8: Контакты сохраняются между запусками и видны клавиатуре (файл в общем контейнере App Group); список отсортирован по имени.
- AC9: Нет доступа к камере → «Нет доступа к камере» и кнопка «Открыть Настройки»; добавление вставкой текста работает.
- AC10: Файл контактов не читается (повреждён) → сообщение об ошибке, файл не перезаписывается пустым списком.

## Состояния экрана
- Пустой список, список.
- Добавление: ввод/вставка, сканер QR, ошибка разбора, свой ключ, дубль, предпросмотр отпечатка и имени.
- Нет доступа к камере.
- Карточка контакта, переименование, подтверждение удаления.
- Ошибка чтения контактов.

## Граничные случаи
- Имя из пробелов, 40 и 41 символ, эмодзи в имени.
- Ключ с пробелами и переносами строк; ключ внутри другого текста (принимается только сам ключ после обрезки пробелов).
- 100+ контактов — список прокручивается, поиск не нужен.
- Двойное нажатие «Сохранить» — один контакт.

## Не входит
- Поиск по контактам, группы, импорт из адресной книги iOS.
- Отметка «отпечаток сверен» — возможно, позже.

## Решения, принятые без пользователя
- Хранилище: JSON в общем контейнере App Group, `NSFileProtectionCompleteUntilFirstUserAuthentication`, исключён из резервных копий (как и приватный ключ, не покидает устройство). Пишется атомарно.
- В симуляторе камеры нет: сканирование QR проверяется автотестом распознавания по картинке, сам сканер — вручную на устройстве.

## Открытые вопросы
