Список: пусто

Вкладка «Контакты» без контактов. В панели навигации нет «+»; единственная кнопка — «Добавить контакт».

Список: с контактами

Строка — имя и первые две группы отпечатка моноширинным. Сортировка по имени без учёта регистра. «+» справа. Третья рамка — 120 сгенерированных контактов на 375 pt (прокрутка).

Новый контакт: пустой лист

Лист `.sheet` поверх списка. Поле ключа пустое, сообщения нет, предпросмотра нет, «Сохранить» недоступна.

Новый контакт: ошибки ключа

Сообщение красным под рядом кнопок. Предпросмотра нет, «Сохранить» недоступна.

Новый контакт: предпросмотр и имя

Ключ валидный: отпечаток в две строки, пояснение, поле «Имя» со счётчиком. «Сохранить» доступна только с валидным именем. На 375 pt — с открытой клавиатурой iOS: лист прокручивается, «Сохранить» над клавиатурой.

Новый контакт: ошибки имени

Сообщение под полем имени; счётчик краснеет при 41+. Последняя рамка — ошибка записи: лист не закрывается, имя сохранено.

Сканер QR

Полноэкранный сканер с кнопкой «Закрыть». Без разрешения — объяснение и два выхода; в симуляторе камеры нет — «Камера недоступна».

Карточка контакта

Push из списка. Имя — заголовок. Поля ключа нет — только показ. «Удалить» — контур красным.

Переименовать

Лист с одним полем, заполненным текущим именем, счётчик, «Отмена»/«Сохранить». Правила имени те же.

Подтверждение удаления

Системный confirmationDialog с именем в заголовке. «Удалить» красная.

Ошибка чтения контактов

Файл повреждён или недоступен. Нет «+» и «Добавить контакт». Файл не перезаписывается.

Клавиатура: строка контактов

Каркас клавиатуры (02) с второй строкой под «Ваш ключ». Только с полным доступом.
