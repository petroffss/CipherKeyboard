# Шифрование и вставка в сообщение

## Суть
В клавиатуре пользователь выбирает получателя из контактов и нажимает «Зашифровать» — в поле сообщения приложения вставляется только шифротекст, внутреннее поле очищается. Отправляет сообщение сам пользователь кнопкой мессенджера.

## Пользовательские истории
- Как пользователь, я хочу в любом мессенджере за одно нажатие превратить набранный текст в шифротекст для выбранного собеседника.
- Как пользователь, я хочу видеть, кому зашифровано сообщение, чтобы не отправить его не тому.

## Критерии приёмки
- AC1: Над внутренним полем — «Кому: <имя> ▾»; нажатие открывает список контактов по имени. Последний выбранный получатель запоминается (id контакта, не текст сообщения).
- AC2: «Зашифровать» недоступна, если поле пустое или из одних пробелов, или получатель не выбран. Контактов нет → «Добавьте контакт в приложении CipherKeyboard».
- AC3: Нажатие «Зашифровать»: в поле приложения в позицию курсора вставляется ровно одна строка `ckmsg1:…`, зашифрованная для получателя и для себя; внутреннее поле очищается; на 2 секунды — «Зашифровано для <имя>». Текст, который уже был в поле приложения, не меняется.
- AC4: Двойное нажатие «Зашифровать» вставляет шифротекст один раз.
- AC5: Ошибка шифрования (нет ключа, Keychain недоступен, текст длиннее 4096 байт) → ничего не вставляется, внутренний текст сохраняется, показывается причина: «Слишком длинное сообщение: N из 4096 байт», «Ключ недоступен — откройте приложение CipherKeyboard». Открытый текст не вставляется никогда, даже как запасной вариант.
- AC6: Получатель расшифровывает вставленную строку (07) и видит исходный текст и имя отправителя из своих контактов; отправитель тоже может её расшифровать.
- AC7: Без полного доступа «Зашифровать» недоступна, баннер объясняет почему (из 04).
- AC8: Счётчик длины появляется, когда текст длиннее 3500 байт: «N / 4096».

## Состояния экрана
- Получатель не выбран; выбран; список контактов открыт; контактов нет.
- Кнопка недоступна / доступна; «Зашифровано для <имя>».
- Ошибка: слишком длинно, ключ недоступен.
- Нет полного доступа.

## Граничные случаи
- Контакт удалён в приложении, пока он выбран в клавиатуре → выбор сбрасывается, «Зашифровать» недоступна.
- Поле приложения уже содержит текст, курсор в середине.
- Ровно 4096 и 4097 байт.
- Клавиатуру скрыли сразу после нажатия — шифротекст вставлен целиком или не вставлен совсем.

## Не входит
- Несколько получателей, кроме себя; автоматическая отправка сообщения.

## Решения, принятые без пользователя
- Себя добавляем в получатели всегда — чтобы читать свои отправленные сообщения.
- Вставка — один вызов `insertText` с готовой строкой; до него никаких вызовов, меняющих поле приложения.

## Открытые вопросы
- Как шифротекст выглядит в чате: технический префикс `ckmsg1:` или понятная человеку подпись вроде «🔒 CipherKeyboard:» перед ним? Ядро (01) находит `ckmsg1:…` внутри любого текста, так что подойдёт любой вариант.
