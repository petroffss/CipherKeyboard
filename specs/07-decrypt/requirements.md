# Расшифровка полученных сообщений

## Суть
Пользователь копирует шифротекст в чате, в клавиатуре жмёт «Расшифровать» — текст показывается внутри панели клавиатуры вместе с отправителем и проверкой подписи. То же можно сделать в приложении на вкладке «Расшифровать», вставив текст.

## Пользовательские истории
- Как получатель, я хочу прочитать зашифрованное сообщение, не выходя из мессенджера.
- Как получатель, я хочу видеть, от кого сообщение и не подделано ли оно.
- Как пользователь, я хочу, чтобы расшифрованный текст никуда не сохранялся.

## Критерии приёмки
- AC1: Кнопка «Расшифровать» в клавиатуре читает буфер обмена только по нажатию. В буфере нет строки `ckmsg1:` → «В буфере нет зашифрованного сообщения. Скопируйте его в чате».
- AC2: Успех: панель поверх раскладки — «От: <имя> ✓ подпись верна», текст с прокруткой, кнопка «Закрыть». Своё сообщение — «От: вы ✓».
- AC3: Подпись верна, но отправителя нет в контактах → «От неизвестного ключа <первые 2 группы отпечатка>» и подсказка «Добавьте контакт в приложении, чтобы видеть имя».
- AC4: Подделано или повреждено → «Сообщение повреждено или подделано», текст не показывается. Не для меня → «Сообщение зашифровано не для вас». Неизвестная версия → «Сообщение из более новой версии CipherKeyboard — обновите приложение».
- AC5: Расшифрованный текст не вставляется в поле приложения, не копируется (кнопки «Копировать» нет), не сохраняется; панель закрывается при скрытии клавиатуры.
- AC6: В приложении вкладка «Расшифровать»: поле вставки и кнопка «Расшифровать» — те же результаты и тексты, что в клавиатуре; результат стирается при уходе с вкладки.
- AC7: Системный запрос iOS на вставку из буфера отклонён → «Нет доступа к буферу обмена» без падения.

## Состояния экрана
- Клавиатура: кнопка «Расшифровать»; в буфере пусто; успех (контакт, вы, неизвестный); подделка; не для меня; новая версия; нет доступа к буферу; нет полного доступа.
- Приложение: пустое поле; те же результаты.

## Граничные случаи
- Длинное сообщение (4096 байт) — прокрутка внутри панели, клавиатура не растёт бесконечно.
- В буфере шифротекст с текстом вокруг (скопировали всё сообщение мессенджера) — ищем первую строку `ckmsg1:` и расшифровываем её.
- Два шифротекста в буфере — расшифровывается первый.
- Контакт отправителя удалён — «От неизвестного ключа …».

## Не входит
- Автоматическая расшифровка без нажатия, история расшифрованных сообщений, копирование открытого текста.

## Решения, принятые без пользователя
- Буфер обмена после расшифровки не очищаем — там шифротекст, он безопасен.
- Доступ к буферу — только из клавиатуры с полным доступом; без него кнопка недоступна с объяснением.

## Открытые вопросы
- Нужна ли кнопка «Копировать» для открытого текста (удобно, но текст окажется в буфере обмена, который видят другие приложения)?
