# Исправления аудита безопасности · 2026-11-03

Это отдельная работа по указанию пользователя. Приёмка 07 остановлена, результаты 01/06/07 относятся к своим ревизиям. Перед возобновлением 07 нужно учесть ниже изменение формата и UI даты в контракте и макете и повторить затронутые проверки на новой сборке.

| Находка | Изменение | Регрессия для приёмки |
|---|---|---|
| Предсказуемые Debug-контакты | Зонды компилируются только для Debug Simulator и требуют явного режима теста. Проверка контроллера держит ключи, книгу и выбор получателя в памяти. Тестам между процессами нужен отдельный флаг; при этом файл получает только публичные ключи случайных личностей, приватные половины не сохраняются. | Без opt-in запуск обычный; в device Debug и Release нет входов в зонды. Контроллер в памяти вставляет один конверт и не меняет общую книгу. |
| Возраст сообщения | Новая запись `ckmsg2` шифрует и аутентифицирует 8 байт времени. `ckmsg1` читается со статусом неизвестной даты. Обе поверхности показывают дату по часам отправителя и предупреждение после семи дней. | Старые и новые золотые векторы, точный UTF-8, чужой получатель, изменённая метка, порог предупреждения, обе поверхности. |
| Лишние копии секретов | В памяти личности хранятся объекты CryptoKit. Статус и повторная сверка пользуются публичным атрибутом той же записи Keychain, рабочий ключ загружается в фоне по действию. Приложение дописывает только публичный атрибут старой записи, не меняя приватные байты. | Метаданные не запрашивают значение секрета. Клавиатура и координаторы шифрования и расшифровки читают секрет по явной операции; подмена метаданных или смена личности блокирует результат. При запуске само приложение загружает личность для инициализации или миграции и хранит в модели только публичный ключ. Миграция не заменяет исходный ключ. |
| Нет машинного контроля вывода | Линтер запрещает новые точки буфера, журнала, файла, Keychain-записи, настроек и обращения к полю хозяина. Исключения задаются точным путём и строкой и не разрешают дубли. | Штатное дерево проходит; искусственное добавление записи открытого текста в буфер или журнал падает. |
| Класс защиты контактов | Новые и заменяемые файлы используют Complete Protection. Приложение пробует повысить класс существующей книги без её переписывания. | Операции контактов, атомарность и исключение из копии сохраняются; на физическом iPhone требуется проверить класс атрибута и отказ чтения под блокировкой. |

Подписанное время относится к часам отправителя. Оно не подтверждает момент доставки и не предотвращает повтор или перенос между чатами. Данные контактов и ключей пользователя не удаляются. Если старый Debug-зонд уже запускался на физическом iPhone, ранее добавленные предсказуемые тестовые контакты необходимо отдельно убрать или заменить; компиляционный запрет сам по себе их не меняет.

## Проверено

- Полный core: 198 тестов в 29 наборах. Тесты извлечения шифротекста: 4/4. Линтер прошёл; отрицательные контроли отклонили буфер, журнал, многострочную запись файла, изменение текста хозяина и дублирование разрешённой строки.
- Runtime 1262494062: Debug и Release для симулятора, Debug для iPhone без подписи/установки и сборка TypingIntegration прошли. В расширении Release и Device Debug из Security импортируется только чтение Keychain. Зонды аудита отсутствуют в Release и Device Debug. Entitlements/plist не изменились. Строгая подпись Release проверена на побайтно идентичной копии без FinderInfo.
- Целевой XCUITest на новом симуляторе: 4/4, 0 ошибок и пропусков (контакты с перезапуском, дата и отправитель, зонд контроллера и отрицательный тест его opt-in). Это не приёмка этапа 07.
- Отдельная миграция на этом симуляторе: до установки старой сборки 0 записей группы, после неё 1; обновление на точный Release аудита оставило тот же rowid и тот же 32-символьный публичный отпечаток. Снимки и сверка байтов установленных бинарников сохранены локально в `.build/audit/`. Приватные байты для проверки не извлекались.
- Физический iPhone не использовался. Проверка класса файла контактов при реальной блокировке устройства и полная нативная приёмка 07 остаются открыты.
